# IntelliBI_Data_Engineering

This project is built using **Databricks** and **PySpark** for data engineering and KPI dashboard development.

## Project Overview
- Implements a **Bronze → Silver → Gold** data pipeline.
- Cleans and transforms raw data for KPI analysis.
- Generates an interactive **Databricks dashboard** showing:
  - Total Orders
  - Gross Revenue
  - Net Revenue
  - Profit Margin

## Technologies Used
- Databricks
- PySpark
- SQL

## Repository Structure
- **Notebooks/** → Contains Databricks notebooks for ETL and KPI logic.
- **README.md** → Project documentation.
